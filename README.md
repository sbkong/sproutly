# 🌱 Sproutly

게임 결과 화면을 캡처하고, OCR로 점수·판정 데이터를 자동 추출해서 기록합니다.

플레이할수록 데이터가 쌓이고, 내 실력이 어떻게 자라왔는지 한눈에 볼 수 있습니다. 

## 기능

- 게임 결과 화면을 단축키 한 번으로 캡처 → OCR → DB 저장
- 점수, 정확도, 판정 디테일(MAX 100% ~ MAX 1%, BREAK) 자동 추출
- 곡별 점수 추이 그래프
- 곡명 검색, 점수 정렬, 이력 조회
- 중복 저장 방지 (이미지 해시 기반)
- 멀티 모니터 지원

## 시스템 요구사항

- Windows 10 이상 (64-bit)
- 화면 해상도 1920×1080 (게임 화면)
- 인터넷(OCR 모델 다운로드)

## 사용법

### 기본 흐름

1. `Sproutly.exe` 실행
2. 게임에서 결과 화면 표시 후 `Ctrl+Shift+R`
3. 앱이 캡처 → OCR → 결과 표시
4. 결과 확인/수정 후 "저장" 버튼

### 단축키

| 단축키           | 기능               |
|-----------------|-------------------|
| `Ctrl+Shift+R`  | 화면 캡처 (전역)   |
| `Ctrl+V`        | 클립보드 이미지 붙여넣기 |
| `Ctrl+H`        | 이력 보기          |
| `Ctrl+T`        | 통계 보기          |
| `Ctrl+,`        | 설정              |
| `Ctrl+Q`        | 종료              |

### 설정

`설정` 메뉴에서 변경 가능:

- 전역 단축키
- 캡처 대상 모니터
- 자동 저장 (캡처 후 즉시 DB 저장)
- OCR 신뢰도 임계값

설정은 exe 옆 `config.json`에 저장됨.

## 데이터 저장 위치

exe 옆에 다음 파일/폴더 자동 생성:

- `records.db` — SQLite 데이터베이스
- `images/` — 저장된 결과 화면 원본
- `config.json` — 사용자 설정
- `crops/` — OCR 디버깅용 임시 (지워도 됨)

PC 옮길 때는 위 파일들을 통째로 복사하면 됨.

## 문제 해결

### exe 실행 시 즉시 종료됨

`debug.bat`에 다음 내용 작성 후 실행:

```
@echo off
set SPROUTLY_DEBUG=1
Sproutly.exe
```

`debug.log`에 에러 메시지가 기록됨.

### 단축키가 동작하지 않음

- 다른 앱이 같은 단축키를 점유 중일 수 있음
- 설정에서 다른 키 조합으로 변경
- 일부 게임은 입력 후킹을 차단함 (해킹 방지). 게임을 창모드/전체창모드로 실행

### OCR 결과가 부정확함

- 게임 해상도가 1920×1080인지 확인
- HUD 스킨이나 게임 패치로 UI 위치가 바뀌면 ROI 좌표 조정 필요
- 결과 패널의 값 셀을 더블클릭하면 수동 수정 가능

### 모델 다운로드 실패

최초 실행 시 PaddleOCR 모델이 자동 다운로드됨 (`%USERPROFILE%\.paddlex\official_models\`).
인터넷이 없거나 방화벽이 막으면 실패함. 다른 PC에서 받은 모델 폴더를 수동으로 복사해도 됨.


## 기술 스택
